# AI-Assisted Therapeutic Journal

Bachelor's thesis — Faculty of Mathematics and Computer Science, University of Bucharest.

An application where patients keep a therapeutic journal between psychotherapy sessions, and AI-based emotion analysis turns those entries into a concise overview for their psychologist — giving a clearer view of how the patient's emotional state evolves over time, with a focus on privacy and the secure handling of sensitive health data.

**Status:** work in progress. The code, documentation and thesis materials will be published in this repository as the project advances.
